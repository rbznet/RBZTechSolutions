RBZ PC Health v0.8.0 RC5 - Report Branding & Presentation

BASELINE
Current GitHub main / v0.8.0 RC4 reporting overhaul.

RC5 CHANGES
- Embeds Assets\rbz-logo.png directly into generated HTML reports.
  The report remains portable: no external image file is required once generated.
- New branded gradient report header.
- Distinct Customer / Technician report title pill.
- Generation timestamp visible in the header.
- Customer/technician-specific report introduction.
- Improved health-score card with individual status chips.
- Scan ID surfaced more clearly.
- Responsive layout improvements for narrower browser windows.
- Better print/PDF page-break behaviour.
- Extra context above Needs Attention.
- Stronger RBZ Tech Solutions footer and report metadata.
- No diagnostic, scoring, priority, Repair Centre or scanner logic changed.

INSTALL
1. Extract this RC5 overlay into the current RBZ-PC-Health repo.
2. Run:
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Apply-RC5.ps1
3. Launch:
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\RBZHealth.ps1
4. Run Full Scan.
5. Generate BOTH:
   - Customer Report
   - Technician Report

TEST
- RBZ logo displays in each HTML report.
- Report remains readable if printed / Save as PDF is used.
- Customer report retains cleaner RC4 customer spacing.
- Technician Workflow remains present in Technician report.
- Priority/Repair Centre sections remain unchanged.
- Health score and finding counts match the app.
- Footer shows company, website, email, report type, scan ID and generated time.
- No blank/broken image icon if the logo cannot be resolved; RBZ fallback is used.
