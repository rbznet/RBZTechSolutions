RBZ PC Health v0.8.0 RC13b
Windows PowerShell 5.1 config-content normalisation fix

ISSUE
RC13a explicitly used ConvertFrom-Json, but on the test machine
Invoke-WebRequest.Content was not being handed to ConvertFrom-Json as one
clean JSON string. The result was:

Invalid JSON primitive: .

FIX
RC13b normalises response content before parsing:
- byte[] -> UTF-8 string
- string -> string
- strips UTF-8 BOM character if present
- checks for empty content
- then calls ConvertFrom-Json

APPLY
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Tools\Patches\Apply-RC13b.ps1
