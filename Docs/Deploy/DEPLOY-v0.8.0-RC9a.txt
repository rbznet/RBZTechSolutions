RBZ PC Health v0.8.0 RC9a - Windows Update action output

Requires:
RC9 applied locally.

Change:
Windows Update Repair Centre actions now show their action Details directly in
the Repair Centre output box beneath the normal Summary and Verification lines.

For Trigger Windows Update scan this includes:
- methods attempted
- COM DetectNow / UsoClient StartScan information
- any request errors
- current Windows Update service state
- reminder that scan/detection is asynchronous and does not mean updates were installed

The same detailed presentation will also help when testing:
- Restart Windows Update services
- Clear Windows Update download cache
- Repair Windows Update components

No repair logic, scoring, scan diagnostics or reports changed.

Patch:
Tools\Patches\Apply-RC9a.ps1

Apply:
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Tools\Patches\Apply-RC9a.ps1

Test:
1. Launch RBZ PC Health as Administrator.
2. Run Trigger Windows Update scan.
3. Confirm the Repair Centre output box displays the Windows Update details.
4. Do not commit until the remaining RC9 actions are tested.
