RBZ PC Health v0.8.0 RC9e
RC9d restart-state initialization hotfix

ISSUE
Apply-RC9d.ps1 accidentally interpolated the intended literal script variables
while patching RBZHealth.ps1, leaving malformed lines such as:

='Light'
=False

This caused RBZHealth.ps1 to fail at launch with:
The term '=False' is not recognized...

FIX
RC9e restores:

$script:Theme='Light'
$script:RestartRequired=$false

RC9e also performs a PowerShell parser check against RBZHealth.ps1 before
reporting success.

NO CHANGES TO
- Repair Centre actions
- network reset logic
- restart-required banner
- diagnostics
- reports
- scoring

PATCH
Tools\Patches\Apply-RC9e.ps1

APPLY
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Tools\Patches\Apply-RC9e.ps1

THEN LAUNCH
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\RBZHealth.ps1
