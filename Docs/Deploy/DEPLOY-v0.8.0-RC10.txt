RBZ PC Health v0.8.0 RC10
Persistent post-restart repair verification

BASELINE
GitHub main:
0a892d0658cc2d76e7498277259723d1d6128ba2
v0.8.0 RC9e expand Repair Centre and add restart-required workflow

PURPOSE
Restart-required repairs previously existed only in memory. After Windows reboot,
RBZ started a fresh session and no longer showed Verify Repairs.

RC10 ADDS

1. Persistent repair state
State file:
%ProgramData%\RBZ Tech Solutions\RBZ PC Health\pending-repair.json

2. Save before reboot
When an action returns RequiresRestart=True, RBZ stores:
- computer name
- action ID/name/category
- performed timestamp
- repair summary
- verification metadata

3. Detect on next launch
If a pending repair exists for the current PC:
- Verify Repairs is immediately available
- pending repair banner is shown
- previous action and timestamp are displayed

4. Clear after verification
After Verify Repairs completes:
- pending state file is deleted
- banner is cleared
- button returns to Run Full Scan

5. Future TEMP cleanup compatibility
Persistent repair state lives under ProgramData, not under the extracted
application/temp directory, so future bootstrap cleanup can remove the temporary
program files without losing repair verification state.

PATCH
Tools\Patches\Apply-RC10.ps1

APPLY
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Tools\Patches\Apply-RC10.ps1

TEST PLAN
1. Apply RC10.
2. Launch RBZ as Administrator.
3. Run Full Scan.
4. Repair Centre -> Reset Windows network stack.
5. Confirm Restart Required.
6. Close RBZ.
7. Confirm state exists:
   Get-Content "$env:ProgramData\RBZ Tech Solutions\RBZ PC Health\pending-repair.json"
8. Restart Windows.
9. Launch RBZ.
10. BEFORE any scan:
    - button should say Verify Repairs
    - pending banner should identify Reset Windows network stack
11. Click Verify Repairs.
12. Confirm button returns to Run Full Scan.
13. Confirm state is gone:
    Test-Path "$env:ProgramData\RBZ Tech Solutions\RBZ PC Health\pending-repair.json"
    Expected: False

Do not commit until the full reboot workflow passes.
