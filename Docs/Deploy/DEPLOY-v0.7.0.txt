2. Run Full Scan.

4. Confirm new findings:
   - Unexpected shutdowns
   - Crash / BSOD history
   - WHEA hardware errors
   - Storage event log health
   - Application crash history
5. Inspect Details for any non-healthy result.
6. Confirm isolated application errors remain Info until thresholds are reached.
7. Generate Customer and Technician reports and check the new findings appear.
8. Confirm Repair Centre, Before/After, Dark mode and responsive scrolling are unchanged.
9. Test on desktop and laptop before committing.
