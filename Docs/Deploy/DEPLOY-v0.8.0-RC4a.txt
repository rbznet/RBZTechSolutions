RBZ PC Health v0.8.0 RC4a

Fixes Defender exclusion report formatting.

Problem:
Get-MpPreference can expose multiple Defender exclusion paths as one combined
string. RBZ therefore counted the combined string as one exclusion and rendered
several paths together on one long line.

Change:
- Normalise semicolon/newline separated exclusion values.
- Detect repeated absolute Windows path roots in a combined value.
- Count the resulting individual exclusions.
- Render each path/process/extension/IP exclusion on its own report line.
- No change to Defender configuration.

Install:
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Tools\Apply-RC4a.ps1

Then:
1. Launch RBZ PC Health.
2. Run Full Scan again.
3. Generate Technician Report.
4. Check Security > Defender exclusions.

The summary should reflect the normalised count and each exclusion should be on
its own line.
