RBZ PC Health v0.8.0 RC3c

Fix:
Application crash/hang findings could inherit the generic Security priority
reason because broad security keywords were evaluated before the more specific
application-stability rule.

RC3c:
- evaluates application crash/hang evidence before the broad security rule
- uses the reason:
  "Repeated application crashes or hangs indicate a recurring software,
   driver or component stability issue that warrants investigation."
- leaves BitLocker/Secure Boot/Defender security reasoning unchanged
- does not modify RBZHealth.ps1

Install:
Extract over the existing repo.

Validate module:
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Test-RC3c.ps1

Launch:
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\RBZHealth.ps1

Then run Full Scan and re-check Application crash history under Technician Priorities.
