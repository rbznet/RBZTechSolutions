RBZ PC Health v0.8.0 RC14
Final release-readiness pass

CHANGES

1. Fix latent Get-RBZSavedTheme fallback defect
The fallback block contained a stray:
=False

It was normally dormant because the configured theme is valid, but it could
break if defaultTheme were ever invalid. RC14 removes the stray statement.

2. Harden build-release.ps1
Before packaging it now verifies:
- Config\settings.json exists and parses as JSON
- Config app.version exactly matches the requested -Version
- required runtime items exist
- RBZHealth.ps1 and all runtime .ps1/.psm1 files pass the PowerShell parser

3. Runtime-only release ZIP
The customer release ZIP now contains only:
- RBZHealth.ps1
- Config\
- Modules\
- Assets\
- Reports\

It intentionally excludes:
- Tools\Patches
- Docs\Deploy
- bootstrap.ps1 / bootstrap-rc.ps1
- build-release.ps1
- source-control metadata
