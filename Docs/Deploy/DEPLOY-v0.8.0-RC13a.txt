RBZ PC Health v0.8.0 RC13a
Stable bootstrap JSON configuration parsing fix

ISSUE
On Windows PowerShell 5.1, raw.githubusercontent.com can return settings.json
with a text/plain content type. Invoke-RestMethod can therefore return a
System.String rather than a deserialized JSON object.

Symptoms:
$config.github
$config.bootstrap

both return nothing, followed by:
Cannot validate argument on parameter 'Uri'. The argument is null or empty.

FIX
bootstrap.ps1 now:
1. Downloads Config/settings.json with Invoke-WebRequest.
2. Verifies response content is not empty.
3. Explicitly pipes response Content through ConvertFrom-Json.
4. Produces a clear error if JSON parsing fails.

APPLY
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Tools\Patches\Apply-RC13a.ps1

RETEST
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\bootstrap.ps1
