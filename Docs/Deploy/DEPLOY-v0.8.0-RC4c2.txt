RBZ PC Health v0.8.0 RC4c2

Recovery / replacement for failed RC4c.

IMPORTANT:
Restore the RC4c backup first:
Copy-Item .\Modules\Report.psm1.v080rc4c.bak .\Modules\Report.psm1 -Force

Then run:
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Tools\Apply-RC4c2.ps1

RC4c2:
- changes only the exact RC4b customer-rendering line
- removes blank/whitespace-only lines from Customer Report details
- preserves all real diagnostic detail lines
- rejoins them with one <br>
- leaves Technician Report detail formatting unchanged
- writes a temporary candidate first
- parses the candidate before replacing Report.psm1
- aborts without touching Report.psm1 if parsing fails

Do not commit until visual testing is accepted.
