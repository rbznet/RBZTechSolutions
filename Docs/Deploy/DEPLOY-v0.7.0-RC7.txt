RC7 TEST:

STARTUP
1. Confirm Startup applications still lists all startup commands.
2. Confirm details now include parsed Target paths where possible.
3. If exact duplicate startup commands exist, confirm `Duplicate startup commands` appears as Recommend.
4. Do not disable startup items automatically.

SERVICES
1. Confirm `Core Windows services` appears.
2. On a normal machine it should normally be Healthy.
3. Open Details and check no obviously normal trigger-start service has been flagged.
4. If `Stopped third-party automatic services` appears, it must be Info only.
5. Missing configured core services are not shown by default.
6. Confirm no existing Event Log, storage/SMART, Device Manager, UI or Repair Centre behaviour changes.

DESIGN NOTE:
RC7 intentionally does NOT flag every Automatic-but-stopped Windows service. Windows trigger-start services may normally be stopped. Only a small configured core-service allowlist is health-scored.
