RBZ PC Health v0.8.0 RC10a

Fixes the RC10 patcher's baseline validation only.

The first RC10 patch incorrectly checked for the internal marker:
RBZ080RC9D_RESTART_REQUIRED

The committed RC9e code contains the restart-required implementation but not
that marker, so the patch stopped before changing RBZHealth.ps1.

RC10a validates the actual RC9e code fragments instead.

No RC10 application changes were made by the failed RC10 attempt because the
guard runs before all replacements/writes.

Apply:
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Tools\Patches\Apply-RC10.ps1

Then launch:
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\RBZHealth.ps1
