RBZ PC Health v0.8.0 RC9b - Repair Centre resizable output pane

Requires:
- RC9 applied.
- RC9a may be applied; RC9b is compatible with its richer Windows Update output.

Change:
The Repair Centre layout now contains a horizontal WPF GridSplitter between:
- the action list / action controls / progress area
and
- the Repair Centre output log.

Behaviour:
- Drag splitter UP to make the output log taller.
- Drag splitter DOWN to make the action list taller.
- Splitter has an 8-pixel grab area.
- Preview resizing is enabled.
- Minimum heights prevent either pane being collapsed accidentally.

No changes to:
- repair/service logic
- diagnostics
- scoring
- reports
- action verification
- Windows Update functionality

Files changed:
- RBZHealth.ps1

Patch:
Tools\Patches\Apply-RC9b.ps1

Apply:
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Tools\Patches\Apply-RC9b.ps1

Test:
1. Apply RC9b.
2. Launch RBZ PC Health as Administrator.
3. Open Repair Centre.
4. Hover over the horizontal divider immediately above the output box.
5. Cursor should become vertical resize cursor.
6. Drag upward and downward.
7. Confirm action list and output log resize smoothly.
8. Run a harmless action such as Trigger Windows Update scan and confirm output still appears normally.
9. Do not commit RC9/RC9a/RC9b until the remaining RC9 repair tests pass.
